# Inkling 2 Mini: a local app-building test

RUNTIME tested the official Thinking Machines Lab Inkling 2 Mini checkpoint on one NVIDIA DGX Spark. This is the documentation companion to **Inkling 2 Mini Built These Apps Locally — What Actually Worked**.

## Read the experiment

- [Setup and exact model identity](SETUP.md)
- [Tasks, checking and repair method](METHOD.md)
- [Measured results and limitations](RESULTS.md)
- [Machine-readable results](results.csv)
- [Episode transcript](TRANSCRIPT.md)

The CSV Field Explorer and browser FPS passed their recorded independent browser checks after repairs. These are two app-building case studies, not a general capability score or a controlled comparison with another model. Code was generated by Inkling; RUNTIME supplied the harness, tests, feedback and hosting.

This release provides experiment documentation and a minimal endpoint-check script. It does **not** bundle the original agent harness, generated apps, browser test suites, private reasoning traces or model weights. The commands let you check the official runtime and attempt the described tasks in your own harness; they do not recreate the exact assertion counts automatically. This boundary matters when comparing results.

Evidence cutoff: November 21, 2026. Documentation published November 26, 2026.

Official sources: [release](https://thinkingmachines.ai/news/inkling-2-mini/), [model card and weights](https://huggingface.co/thinkingmachines/Inkling-2-Mini), [DGX Spark recipe](https://recipes.vllm.ai/thinkingmachines/Inkling-2-Mini?hardware=dgx_spark_gb10&features=reasoning,tool_calling,spec_decoding).

## Quick endpoint check

After following SETUP.md, run `python3 check_endpoint.py`. It uses only Python's standard library and sends a small text request to your loopback endpoint. It does not start services, download weights or execute model-proposed commands.
